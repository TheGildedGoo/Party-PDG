# Parked Fibbage prompts

These files are the old free-text Fibbage bank (`prompt`, `answer`, `lies`).

The shipped game bank does not load them. Decoy Brief replaced that mode with multiple choice: one handbook line and exactly three decoys. Useful truths from these prompts were converted into `tools/items/decoy.py`.

Do not point `build_bank.py` or `import_questions.py` back at this folder.
